# 💡 Light It Up

A minimalistic 2D platformer inspired by *Light It Up* Theme .  
Jump, flip, and glow your way through floating obstacles — every move lights up the world.

---

## ✨ Features
- Physics-based jump and movement system  
- Dynamic glowing visuals and trails  
- Smooth camera and responsive controls  
- Multiple levels with progressive difficulty  

---

## 🛠️ Built With
- **Engine:** Unity 2D  
- **Language:** C#  
- **Tools:** Visual Studio, Unity Animator  

---

## 🎮 Controls
| Action | Key |
|--------|-----|
| Move | A / D |
| Jump | Space |
| Restart Level | R |
